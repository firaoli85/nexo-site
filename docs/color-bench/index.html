Color hardening bench — C3

One question: which of these distinctions survive on your worst screen? Identity is not in question — the palette is Railway-derived and you re-picked it blind. Deltas are. Every specimen is numbered so a reading converts to a value.

Reading protocol

  1. In sections a, b, c and e: note the FIRST VISIBLE step number — the lowest number where you can see the distinction at all.
  2. In section d: note any text-ramp row that becomes hard to read.
  3. In section f: note any fragment where CURRENT loses structure — where the shape stops reading as a card, a bar, or an edge.

Good monitor first, then the old and cheap machines. Those second readings write the thresholds — the good-monitor pass is only the control.
