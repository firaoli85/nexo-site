Type specimen bench — P3-W3

Every block shows the same real copy from the live site at the same sizes. Only the typeface changes. React by candidate number.

Block 1 is the incumbent exactly as it ships today. Block 2 is the control that matters: the same incumbent family pushed to its heavy cuts, testing whether weight — not family — was the wound.

The mono accent rotates across blocks so all three technical faces get seen; each is labelled. Every block ends on an --ink strip, because our pages end on ink and a face has to survive both registers.

Fonts here load from a CDN for bench purposes only. Production loading is a separate later decision tied to C1 and is made at implementation, not here.
